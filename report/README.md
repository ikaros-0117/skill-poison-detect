# 汇报材料目录

本目录为项目 `skill-poison-scan`（Skill 投毒安全检测服务）的可汇报材料落盘位置。

| 文件 | 说明 |
|---|---|
| `index.html` | 完整版 HTML 汇报文档（含架构/时序/状态机 Mermaid 图，依赖 jsDelivr CDN）。适合正式评审、开发交接。 |
| `pitch.html` | 精简版 PPT 风格汇报页面（10 页，方向键 / 空格翻页，含导航点与上/下页按钮）。适合对外交付、客户汇报。 |

## 汇报文档涵盖内容

1. 项目概览（目标、组成、能力清单）
2. 系统架构（总体架构图、职责边界、关键设计决策）
3. 对外 API（HMI / M2M / Health 接口清单、请求字段、任务响应字段）
4. 内部设计（Server 模块划分、任务状态机、一次扫描数据流、数据模型、Redis 队列契约）
5. 检测引擎与规则（引擎薄封装接口、17 类 72 条规则目录、LLM 语义分析）
6. 使用指南（快速开始、冒烟测试、关键配置）
7. 可靠性 / 可观测 / 安全（熔断、限流、自愈、监控、鉴权预留）
8. 项目结构
9. 进度与后续规划
10. 许可证说明

## 打开方式

- 完整版：`open index.html`
- PPT 风格：`open pitch.html`（用键盘 ← / → / 空格 翻页）
- 需要联网以加载 Mermaid 图表脚本；若离线，文字内容仍完整可读，仅架构图不渲染。
