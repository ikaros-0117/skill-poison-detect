背景与痛点

Skill 正成为新的攻击面，需要规模化防线

🧩

投毒手段隐蔽

Skill 是“代码 + 指令”的混合体，提示注入、数据外泄、恶意脚本常隐藏在说明与依赖中，肉眼难以识别。

⚙️

人工审查不可规模化

Skill 数量快速增长，CI 流水线与安装流程需要自动化、可重复的安全门禁。

📐

缺少统一标准

缺乏一致的风险评分、修复建议与可审计报告，安全结论难以量化与追溯。

在 Skill 被安装 / 运行之前，完成检测、评分与拦截。

检测能力

静态规则

正则 / AST / 污点追踪 / YARA 恶意样本匹配，不依赖 LLM 即可发现确定性风险。

语义分析（可选）

风险评分

输出 0-100 风险分、严重级别、安全建议与可配置门禁 pass/fail。

对外 API06 / 10
使用方式

三步即可接入

1

配置

复制 .env.example，按需填写内部 LLM 网关（纯静态可跳过）。

2

启动

docker compose up --build -d 一键拉起服务与基础设施。

3

扫描

上传 Skill zip，轮询结果或直接下载 SARIF 接入流水线门禁。

# 冒烟测试：一个良性 skill 包
printf -- '---\nname: demo\ndescription: demo\n---\n# demo\n' > /tmp/skill-test/SKILL.md
(cd /tmp/skill-test && zip -r ../skill-test.zip .)

curl -F "file=@/tmp/skill-test.zip" -F "useLlm=false" http://localhost:8080/api/v1/scans
curl -F "file=@/tmp/skill-test.zip" -F "useLlm=false" http://localhost:8080/api/m2m/v1/scans
